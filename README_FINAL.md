# 《预警之前：灾害决策模拟器》

## 项目简介
一款面向大学自然灾害课程的互动纪录片式防灾减灾决策模拟器。玩家在暴雨、积水、封路和通讯受限的连续情境中做出选择，并在结尾查看决策复盘。

## 启动

双击 `START_WINDOWS.bat`，按窗口提示在浏览器打开本地地址。也可直接打开 `index.html` 进行快速预览。

## 体验

点击“进入体验”，按每个场景给出的行动选项推进；可使用“返回上一个决定”回看上一节点。教师模式用于课堂讲解状态变化。

## 文件结构

`index.html` 为入口；`css/` 为样式；`js/` 为运行逻辑；`data/` 为剧情与视觉绑定；`assets/` 为本地视觉素材；`docs/` 为课程与 QA 文档。

## 注意事项

项目应通过本地服务运行，以确保 JSON 与图片资源正常加载。视觉参考图仍标记为 `TEMP_UPSCALED_REFERENCE`，用于课程展示与交互验证。
